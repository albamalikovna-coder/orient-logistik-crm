# Инструкция по настройке OrientLogistik

Для того чтобы я мог развернуть систему в облаке, выполните следующие шаги:

### 1. Подготовка GitHub
- Создайте новый пустой репозиторий на GitHub (например, `orient-logistik-crm`).
- Пришлите мне ссылку на него.

### 2. Подготовка Supabase (База данных)
- Зайдите на [supabase.com](https://supabase.com) и создайте новый проект.
- В разделе **SQL Editor** создайте новый запрос и вставьте содержимое файла `database_schema.sql` (я его уже подготовил). Нажмите **Run**.
- В разделе **Project Settings -> API** найдите:
    - `Project URL`
    - `API Key (anon public)`

### 3. Секреты (Environment Variables)
Создайте файл `.env.local` в корне проекта (или я помогу его заполнить) с такими данными:
```
NEXT_PUBLIC_SUPABASE_URL=ваш_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_key
```

### 4. Что делаю я дальше
Как только вы дадите доступ к репозиторию или подтвердите готовность, я:
1. Сгенерирую код компонентов (Авторизация, Список заказов, Карточка товара).
2. Настрою деплой на Vercel (бесплатно), чтобы сайт открывался по адресу `orient-logistik.vercel.app`.
